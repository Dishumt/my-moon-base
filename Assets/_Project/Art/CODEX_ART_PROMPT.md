## 1. Що за гра і який у неї настрій

- Браузерна 2.5D-гра для дітей **7–12 років** (Unity 6.6, URP, збірка WebGL). Гравець — головний інженер бази на південному полюсі Місяця. Він будує модулі з роботами, ходить по поверхні до кратерів з льодом, розподіляє енергію і береже екіпаж з 4 астронавтів від радіації.
- **Настрій — затишна, дружня наукова пригода.** Це не жахи і не війна. Небезпека є (радіація, сонячна буря), але ми показуємо її кольором і значками, а не страшними картинками. Ніхто не помирає, вибухів немає: якщо політ невдалий, ракета просто розвертається і летить назад.
- **Головний принцип дизайну: 7-річна дитина з першого погляду розуміє, що де.** Де вода, де кисень, де їжа, де небезпека і хто з астронавтів хто. Якщо картинку треба пояснювати словами, її треба спростити.

## 2. Як побудований кадр (2.5D, як у Don't Starve Together)

- **Світ тривимірний.** Камера перспективна (як справжня камера: далекі речі менші), дивиться згори під кутом ≈45° і їде за інженером.
- **Модулі бази — прості 3D-форми** (бочка, тунель, купол) з мультяшним шейдером: 3 рівні світла і темний контур. Для них потрібні **текстури** — квадратні картинки, якими «обклеюють» 3D-форму (підлога, стіни, дах).
- **Усе інше — 2D-спрайти-білборди.** Спрайт — це плоска картинка з прозорим фоном, а білборд — спрайт, який завжди повернутий до камери. Так зроблені персонажі, роботи, меблі, каміння, кратери й іконки над головами.
- Коли інженер заходить у модуль, дах зникає, видно меблі всередині, а вулиця навколо темнішає.

## 3. Стиль малювання

Тримайся файлів, які вже є: вони і є еталоном. Найкращі зразки:
`Characters/engineer_orange_outdoor/front.png`, `Characters/engineer/engineer_front.png`, `Characters/robot/construction_01.png`, `Props/Furniture/bunk_bed.png`, `Props/Moon rocks/crater_with_ice_crystals.png`, `Icons/Resources_128/water.png`.

- **Піксель-арт** (картинка з чітких квадратних пікселів, без розмиття) з **темним контуром** 1–2 px навколо кожного предмета.
- **Затінення** м'яке, 3–4 тони на кожен колір. **Світло падає зверху-зліва.** На блискучому (скло шолома, крапля, кристал льоду) — маленький білий блік.
- **Великі прості форми і чіткий силует.** Предмет має впізнаватися навіть зменшеним удвічі. Дрібні деталі малюй, тільки якщо їх видно в грі.
- **Ракурс меблів і каміння — 3/4 згори-спереду:** видно і верх, і передню стінку, як у `bunk_bed.png`.
- **Персонажі** мають мультяшні пропорції (велика голова), **але це дорослі фахівці 25–45 років**: доросле обличчя, робоча форма, впевнена постава. Не малюй їх схожими на дітей: правила Space Apps забороняють зображувати людей молодше 18.
- Фон завжди **прозорий** (PNG з альфа-каналом, тобто з прозорістю). Виняток — текстури підлоги, стін і ґрунту.

## 4. Кольори: колір = значення

Кольори ресурсів **фіксовані й однакові всюди**: в іконках, у світі та в інтерфейсі. Не використовуй їх для прикраси там, де вони щось «не означають». Наприклад, фіолетовий у нас означає радіацію, тому випадковий фіолетовий предмет заплутає дитину.

| Що | Колір | hex |
|---|---|---|
| ⚡ Енергія (а також вантаж і паливо) | жовтий | `#FFC83D` |
| 💧 Вода | синій | `#3D8BFF` |
| 💨 Кисень | блакитний | `#5FD4F4` |
| 🥬 Їжа | зелений | `#58C46A` |
| ☢️ Радіація, сонячна буря | фіолетовий | `#A569E8` |
| Добре / увага / тривога | зелений / помаранчевий / червоний | `#58C46A` / `#FF9A5C` / `#FF4D5E` |
| Доза радіації в астронавта | зелена → жовта → червона зона | |

- **Місяць холодний:** сірий з легким фіолетово-блакитним відтінком (дивись `Environment/Seamless Gray-Purple Lunar Soil Texture.png`). Лід у кратерах — світло-блакитні кристали.
- **База тепла:** білі панелі, помаранчеві смуги, теплі жовті лампи (дивись `Environment/moon_base_wall_512.png`). Через цей контраст дитина одразу бачить, де «дім», а де «надворі».

## 6. Розміри і точки опори — НЕ змінювати

Код гри знаходить кожну картинку **за точним шляхом та ім'ям файлу**, а налаштування імпорту (як Unity читає картинку) виставляють меню техліда `Moon → Налаштувати …`. Тому нові картинки мусять мати ті самі розміри й ту саму «точку опори» — місце, яким предмет стоїть на землі.

| Що | Полотно (px) | Де низ предмета | Імпорт (ставить техлід) |
|---|---|---|---|
| Персонаж | 128×128 | ноги по центру, на ≈124-му рядку з 128 | PPU 72 (≈1,7 м), pivot (0.5, 0.03), фільтр Point |
| Робот | 128×128 | низ гусениць біля нижнього краю | PPU ≈100 (≈1,2 м), pivot знизу |
| Меблі | 256×256 | низ предмета на ≈238-му рядку з 256 | PPU 115 (≈1,85 м), pivot (0.5, 0.07) |
| Каміння, кратери | 128×128 | низ біля нижнього краю | |
| Іконки ресурсів | 128×128 | по центру | |
| Іконки стану над головою | 64×64 | по центру | PPU 140 (≈0,45 м) |
| Текстури (ґрунт, підлога, стіни, дах) | 512×512, **безшовні** (повторюються без видимих стиків) | — | Texture Type Default, Wrap Repeat |
| Ракети | 256×256 або 512×512 | | |
| Обкладинка itch.io | 630×500 | | |

PPU (Pixels Per Unit) — скільки пікселів картинки займає 1 метр у грі. Pivot — точка, за яку гра «ставить» картинку на землю. Фільтр Point — показ пікселів без згладжування (для піксель-арту).

## 8. Інтерфейс (планшет) — свій окремий стиль

Світ — теплий мультяшний піксель-арт, а планшет інженера — **«консоль інженера»**: темно-синій фон `#04101A`, тонкі рамки `#2B5675`, блакитний акцент `#5FD4F4`, кутові скоби, прямі кути, ВЕЛИКІ літери, моноширинний шрифт (усі літери однакової ширини) JetBrains Mono з ліцензією OFL. Повна палітра — у `docs/design/STYLE_FOR_CLAUDE_CHAT.md` і `Assets/_Project/UI/Common/Theme.uss`. Ці файли не змінюй: це зона ролі 05.

Для інтерфейсу роль 02 малює:
- **9-slice рамки** (`Art/UI/card_frame.png` тощо). 9-slice — картинка, яку Unity розтягує, але не чіпає кути. Зрізаний кут і світіння живуть усередині картинки, кути ≈14 px не мають розтягуватися.
- **Іконки для карток і вкладок — білий одноколірний силует** на прозорому фоні. Колір їм дає код (tint — розфарбування картинки кодом), тому кольорова іконка там вийде брудною.
- **Шрифт** JetBrains Mono кладемо в `Art/Fonts/`.

## 11. Як працювати з файлами

- **Моя зона:** тільки `Assets/_Project/Art/` і `docs/CREDITS.md`. Не чіпай сцени `.unity`, префаби, `Scripts/`, `UI/`, `Resources/`. Якщо для картинки треба змінити код, напиши текст повідомлення для техліда (роль 01), а сам нічого там не правь.
- 🔑 **Головний трюк — заміна заглушки:** нову картинку зберігай **з тим самим ім'ям у тій самій папці** поверх старої. Unity оновить її в грі сама.
- **Файли `.meta` не видаляй і не змінюй.** У них зберігається ідентифікатор, за яким гра знаходить картинку. Для нових PNG `.meta` створить Unity, коли я відкрию проєкт, і тоді я закомічу PNG разом з `.meta`.
- **Не перейменовуй і не переміщуй наявні файли:** код шукає їх за шляхом (наприклад, `Environment/Seamless Gray-Purple Lunar Soil Texture.png`), навіть якщо в імені є пробіли.
- **Імена нових файлів:** англійською, малими літерами, через `_`, без пробілів (`roof_greenhouse.png`).
- **Git:** окрема гілка `02-art/<що-зробив>`, маленькі коміти. Ніколи не пуш у `main` і ніколи не використовуй `--force`.
- **Позначка ШІ:** текстовий файл, який ти створюєш, починай рядком `<!-- AI-assisted: written with Codex. See docs/AI_USE.md -->` (у `.md`) або `// AI-assisted: written with Codex. See docs/AI_USE.md` (у коді).
- **Як перевірити:** скажи мені, що відкрити в Unity. Зазвичай це сцена `Assets/_Project/Scenes/Sandbox/02-Art.unity`: перетягнути картинку зі вікна Project у сцену, глянути в Inspector розмір і точку опори, натиснути Play.
