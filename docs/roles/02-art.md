# 02 · Арт-дизайнер

> Ти відповідаєш за те, як гра виглядає. Стиль — **як у Don't Starve Together**: світ тривимірний, а персонажі, роботи, каміння й предмети — це 2D-малюнки. Модулі бази — прості 3D-коробки, і для них ти малюєш текстури та меблі.
>
> Важливе правило хакатону: **спершу швидкі заглушки для всіх, потім краса.** Іншим потрібні хоча б прості картинки правильного розміру.

**Твоя зона:** `Assets/_Project/Art/` і `docs/CREDITS.md`.

---

## Як працювати над кожною задачею

1. Малюєш у своїй програмі (Photoshop, Krita, Aseprite, Procreate…) і експортуєш **PNG з прозорим фоном**.
2. Оновлюєш проєкт:
   - Claude Code: `/sync`;
   - GitHub Desktop: **Fetch origin** → Branch → **Update from main**.
3. Кладеш файл у потрібну папку `Assets/_Project/Art/...`: перетягни у вікно Project в Unity або просто скопіюй у папку. Unity сам створить файл `.meta`.
4. Налаштовуєш імпорт (див. нижче) і перевіряєш картинку у своїй сцені `Scenes/Sandbox/02-Art.unity`.
5. Зберігаєш у git:
   - **GitHub Desktop:**
     1. New branch `02-art/<що-зробив>`.
     2. Галочки на нових файлах **разом з `.meta`**.
     3. Commit → Push → Create Pull Request.
   - **Claude Code:**
     > Я роль 02. Створи гілку 02-art/<що-зробив>, закоміть нові та змінені файли з Assets/_Project/Art разом з .meta, запуш і створи Pull Request.
6. Пишеш у чат команди, що додав.

### Як налаштувати картинку в Unity

Вибери файл у вікні Project і в Inspector постав:
- **Texture Type** = Sprite (2D and UI). Для текстур підлоги, стін і даху залиш Default;
- **Pixels Per Unit** = 100 (однаково для всіх картинок!);
- **Pivot** = Bottom (низ по центру) для персонажів, роботів, меблів і каміння, Center для іконок;
- **Filter Mode** = Bilinear (для піксель-арту Point);
- натисни **Apply**.

### 🔑 Головний трюк: заміна заглушки

Готову картинку зберігай **з тим самим ім'ям файлу** поверх заглушки. Unity оновить її скрізь у грі сама, і нікому нічого не треба переробляти.

## Задача 1. Стиль і домовленості (перші 2 години, Unity ще не потрібна)

1. **Палітра** на 6–8 кольорів. Місяць сіро-блакитний, база тепла: помаранчевий, білий. Ресурси мають свої кольори:
   - енергія жовта;
   - вода синя;
   - кисень блакитний;
   - їжа зелена;
   - радіація фіолетова.
2. **Ракурс:** з техлідом (01) домовтеся про кут камери (≈40–45°). Персонажі й роботи — у **3 напрямках**: спереду, ззаду, збоку (інший бік дзеркалимо), як у DST.
3. **Розміри:** персонаж ≈ 128 px заввишки, меблі 64–256 px, іконки 128×128, текстури 512×512 (і щоб повторювалися без швів).
4. **Для дітей 7–12:** чіткі силуети, великі деталі, дружні обличчя, нічого страшного.
5. **4 астронавти мають відрізнятися з першого погляду:**
   - інженер: помаранчевий, з інструментом;
   - медик: білий, із зеленим хрестом або сердечком (червоний хрест — захищений знак, його не використовуємо);
   - ботанік: зелений, з рослиною;
   - геолог: коричневий, з молотком.

   Усі вони **дорослі**: правила Space Apps забороняють зображувати людей молодше 18.
6. Збери 5–10 референсів в одну дошку і покажи команді.

## Задача 3. Запуск і планшет P2 (години 9–15)

- **Запуск:** `Launch/earth.png`, `moon.png`, `rocket.png` і пунктир для дуги польоту. Кожне окремим файлом, бо дугу анімує роль 04. Якщо політ невдалий, ракета **розвертається і летить назад**. Вибухів не малюємо.
- **Вантажі:** іконки води, їжі, будматеріалів, панелі, батареї, ліків, палива і «місце для людини».
- **Світлофор:** зелений, жовтий, червоний.
- **Планшет:** `UI/tablet_frame.png`, 5 іконок вкладок (мапа, ресурси, екіпаж, поставки, зв'язок), кнопки, а також кнопки швидкості: пауза, ×1, ×2.
  - Рамки й кнопки, які розтягуються, налаштуй як 9-slice: Inspector → Sprite Editor → потягни зелені рамки так, щоб кути не розтягувалися.
- **Бура:** фіолетове сяйво поверх екрана й значок попередження.

## Задача 4. Краса P3 (години 20–30)

- Замінюй заглушки готовим артом, починаючи з того, що найбільше видно: персонажі, модулі, поверхня.
- Анімації по 2–4 кадри: хода астронавтів і роботів, робот будує, геолог копає. Кадри здаєш окремими файлами `robot_build_1..4.png`, а підключає їх 01.
- Логотип гри і 5 маленьких ілюстрацій розділів.

## Задача 5. Подача P4 (години 30–36)

- Обкладинка для itch.io **630×500** і 3–5 скріншотів.
- Візуал для демо (відео до 30 с або до 7 слайдів) разом з капітаном. Усе англійською.

## Правила (з правил Space Apps)

- ❌ **Ніяких логотипів, прапорів і емблем місій NASA**, у тому числі в картинках, згенерованих ШІ. Можна писати «використано відкриті дані NASA».
- ❌ **Ніяких зображень людей молодше 18.**
- **Картинки, згенеровані ШІ**, мають **видимий водяний знак** (наприклад, маленький напис «AI» у кутку) і рядок у `docs/AI_USE.md`. Простіше малювати самому.
- Чужі асети беремо тільки з відкритою ліцензією (наприклад, Kenney, CC0). Кожен записуємо в `docs/CREDITS.md`: що, звідки, ліцензія.
