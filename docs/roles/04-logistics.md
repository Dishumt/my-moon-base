# 04 · Запуск, поставки й екіпаж

> Ти відповідаєш за все, що пов'язує базу із Землею і що робить екіпаж:
> - запуск ракети з механікою «світлофора»;
> - поставки за розкладом і вікна зв'язку;
> - завдання для 4 астронавтів: видобуток льоду, зразки, теплиця, наука;
> - резерв людей на Землі.
>
> Твій екран запуску — **перше, що бачить гравець і судді**, тож він має бути зрозумілим і ефектним.

**Твоя зона:** `Scripts/Logistics/`, `UI/Launch/`, `Resources/Data/Launch/`, `Tests/EditMode/04*Tests.cs`, сцена `Scenes/Sandbox/04-Logistics.unity`.

## Як працювати над кожною задачею

1. Оновись: `/sync` у Claude Code або в GitHub Desktop **Fetch origin** → Branch → **Update from main**.
2. Створи гілку `04-log/<задача>`: попроси Claude або в GitHub Desktop → New branch.
3. Почни **нову** сесію Claude. **У чаті claude.ai** спершу завантаж `CLAUDE.md`, цей файл і файли, які будеш міняти.
4. Встав підказку із задачі нижче. Прочитай план Claude. Якщо щось незрозуміло, пиши «поясни простіше».
5. **У чаті** збережи кожен файл, який дав Claude, точно за вказаним шляхом.
6. Перемкнись в Unity, дочекайся компіляції і перевір, як описано в «Перевірка».
7. Працює → коміт. Не працює → встав Claude помилку з Console.
8. Задача готова → push, Pull Request і злий його сам (див. `docs/GIT_HOWTO.md`). Напиши в чат команди, що злив.

**Як перевіряти:**
- **Тести:** Window → General → Test Runner → EditMode → Run All.
- **Твоя сцена** `04-Logistics`: там є DebugPanel і UIDocument для екрана запуску.
- **Інтерфейс** можна подивитися без Play: двічі клацни файл `.uxml`, і він відкриється в **UI Builder**.

## Як працює твоя частина гри

- **Запуск:** гравець кладе вантаж у корабель і вибирає, скільки палива залити. **Паливо теж важить:** що більше вантажу, то більше треба палива.
  - 🟢 палива із запасом: політ точно вдалий;
  - 🟡 впритул: показуємо ризик у %, а далі вирішує випадок;
  - 🔴 палива не вистачить: корабель розвертається на Землю.
- **Перша місія** везе екіпаж: 4 місця по 150 кг уже зайняті, плюс вантаж. Якщо політ невдалий, гравець перепаковує й пробує ще раз.
- **Поставки:** приблизно кожні 4 дні, на посадковий майданчик. Невдалий політ → база чекає на 3 дні довше. Замовлення можна відправити **тільки у вікно зв'язку**.
- **Зв'язок:** на південному полюсі Земля частину часу за горизонтом. У планшеті є календар вікон. Пропустив вікно — поставка приходить пізніше.
- **Завдання екіпажу:**
  - гравець дає завдання трьом астронавтам (інженером він керує сам);
  - астронавт іде на місце (його веде світ від 01), а коли `AtTaskSite`, починає працювати;
  - **спеціаліст робить свою роботу вдвічі швидше**;
  - хто хворіє легко (`Sick`), працює вдвічі повільніше.

  | Завдання | Де | Що дає | Спеціаліст |
  |---|---|---|---|
  | Добувати лід | кратер (надворі) | вода | геолог |
  | Збирати зразки | точка зразків (надворі) | наука | геолог |
  | Теплиця | теплиця | урожай ×1.5 (рахує 03) | ботанік |
  | Лабораторія | лабораторія | наука | будь-хто |
  | Лікувати | медмодуль | лікування (рахує 06) | медик |
  | Ремонт | де поломка | ремонт | інженер |
  | Відпочинок | житловий | нічого, але безпечно | — |
- **Резерв:**
  - на Землі чекають люди на заміну, і людина в поставці займає **150 кг**;
  - хто досяг ліміту радіації (`GoingHome = true`, це ставить роль 06), летить додому тим самим кораблем;
  - роль у заміни та сама, наприклад геолог на геолога.

## Задача 0. Список вантажів (перші години, Unity ще не потрібна)

**Підказка:**
> Я роль 04. Прочитай CLAUDE.md і docs/GAME.md. Створи Resources/Data/Launch/cargo_items.json: для кожного вантажу id, ключ назви, маса в кг, що дає базі (water +20, food +10, materials +20, medkits +1, solar_panel_kit, battery_kit, crew_seat). Також launch.json з числами запуску і tasks.json зі швидкостями завдань з мого файлу ролі. І [Serializable] класи в Scripts/Logistics/Data/.

**Числа запуску** (стартові, потім підбиратимеш):

| Що | Значення |
|---|---|
| Маса порожнього корабля | 1000 кг |
| Потрібне паливо | 1.5 × (1000 + маса вантажу й людей) |
| Найбільший бак | 6000 кг |
| Запас = паливо / потрібне паливо | ≥ 1.1 🟢 · 0.9–1.1 🟡 · < 0.9 🔴 |
| Шанс успіху в жовтій зоні | від 30% (запас 0.9) до 95% (запас 1.1) |
| Людина | 150 кг |
| Видобуток льоду | +12 води/день (геолог), +6 (інші) |
| Зразки | +3 науки/день (геолог), +1.5 (інші) |

## Задача 1. Розрахунок запуску (`LaunchCalculator`)

**Підказка:**
> Реалізуй LaunchCalculator — звичайний C#-клас без MonoBehaviour: за списком вантажу, людьми і паливом повертає масу, потрібне паливо, запас, колір (Green/Yellow/Red), шанс успіху у %. Метод Roll(random) вирішує результат, щоб у тестах можна було підставити «випадковість». Числа з launch.json. Тести для всіх кольорів і меж 0.9 та 1.1.

**Перевірка:** тести зелені. Спитай Claude «поясни мені формулу на прикладі 2000 кг вантажу» і перевір, що розумієш її сам. Тобі ж пояснювати її суддям.

## Задача 3. Анімація польоту

**Підказка:**
> Додай анімацію польоту: картинка ракети (Art/Launch/rocket.png від ролі 02) летить по дузі (крива Безьє) від Землі до Місяця за 3 секунди через корутину. Невдалий політ — долітає до середини, розвертається і повертається. Після анімації — GameEvents.LaunchFinished.

## Задача 4. Поставки (`SupplySystem`)

**Підказка:**
> Реалізуй SupplySystem: розклад (кожні N днів з balance), стани замовлення Чернетка → Відправлено (тільки якщо CommsSystem.IsOpen) → Запущено → Прибуло / Повернулось. Прибуття: ресурси в GameState, люди в Crew, ті, у кого GoingHome, відлітають. Повернення — прибуття на 3 дні пізніше. Перша місія розділу 1 — той самий екран запуску з 4 зайнятими місцями. Тести.

## Задача 5. Зв'язок (`CommsSystem`)

**Підказка:**
> Реалізуй CommsSystem: вікна зв'язку за шаблоном у годинах (наприклад, 30 годин є, 18 немає), метод IsOpen(), список найближчих вікон для календаря в планшеті. Якщо антені не дали енергії (Power.Comms = 0), вікно закрите. Тести.

## Задача 6. Завдання екіпажу (`CrewSystem`)

**Підказка:**
> Реалізуй CrewSystem: метод Assign(astronaut, task, targetId) ставить Task і TaskTarget (повертає ключ тексту з причиною, якщо не можна: InsideOnly → тільки завдання всередині; Severe → тільки медмодуль). Щогодини, якщо AtTaskSite: MineIce додає воду і зменшує Amount у точки, CollectSamples і Lab додають науку; спеціаліст ×2, Sick ×0.5. Метод RecallAllInside() — усіх у укриття (для бурі). RequestReplacement(astronaut) — людина з резерву в наступну поставку. Тести.

**Перевірка:** у DebugPanel дай геологу «Добувати лід» і тисни «+1 година». Вода росте, а коли хтось інший на тому ж завданні, вона росте повільніше.
