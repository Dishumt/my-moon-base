## Задача 1. Каркас (перші 2–3 години, усі чекають на тебе!)

Готувати каркас можна. Але хакатон уже йде, тож роби його **першим**.

**Мета:** у `main` лежить проєкт, де кожна роль має свою папку, свою сцену і файли-заготовки своїх систем.

**Як зробити:**
1. Склонуй репозиторій (капітан уже виклав туди документи).
2. Unity Hub → New project → **Unity 6.6** → **Universal 3D** → створи проєкт **в окремій тимчасовій папці**.
3. Закрий Unity і перенеси з тимчасової папки в папку репозиторію три папки: `Assets/`, `Packages/` і `ProjectSettings/`.
4. Впиши точний номер версії Unity в README (`6000.6.___`).
5. Відкрий проєкт з папки репозиторію. Edit → Project Settings → Editor: має стояти Version Control = **Visible Meta Files**, Asset Serialization = **Force Text**.
6. Дай Claude підказку:
   > Я техлід (роль 01). Прочитай CLAUDE.md і docs/GAME.md. Створи каркас:
   > 1) папки з таблиці власників;
   > 2) Game.asmdef у Scripts і Tests/EditMode/Game.Tests.asmdef для EditMode-тестів;
   > 3) у Scripts/Core:
   >    - GameState з усіма класами даних з CLAUDE.md;
   >    - GameClock (реальний час, день ≈ 3 хв з balance.json, пауза, ×1/×2, Tick кожну ігрову годину, OnDayEnd);
   >    - ISimSystem, DayReport, GameEvents;
   >    - DataLoader (JSON з Resources через JsonUtility);
   >    - Loc (Loc.Get(key) з texts_en/texts_uk.json);
   >    - SaveSystem (PlayerPrefs);
   >    - GameBootstrap (створює GameState з chapter_01.json і реєструє системи в порядку з CLAUDE.md);
   >    - DebugPanel (OnGUI: стан гри, кнопки «+1 година», «+1 день», «Пауза»);
   > 4) заготовки всіх систем у папках ролей, з порожніми Tick/OnDayEnd і коментарем TODO, щоб усе компілювалося;
   > 5) мінімальні JSON: Balance/balance.json, Chapters/chapter_01.json, Text/texts_en.json, texts_uk.json.
   > Пиши так, щоб новачки розуміли: короткі класи, коментарі українською, у кожному файлі рядок AI-assisted.
7. Перемкнись в Unity, і Console має бути чиста.
8. Створи сцени (це вручну):
   - `Scenes/Main.unity`:
     - площина-земля, камера, кубик-інженер, `GameBootstrap`;
     - об'єкт `UIDocument` з Panel Settings для планшета (UXML туди підключить роль 05);
   - `Scenes/Sandbox/02-Art.unity`, `03-Simulation.unity`, `04-Logistics.unity`, `05-UI.unity`, `06-Radiation.unity`:
     - камера як у Main, світло, `GameBootstrap`, `DebugPanel`;
     - у 04 і 05 додай ще `UIDocument`.
9. Window → General → Test Runner → EditMode: переконайся, що тестова збірка видна.
10. Створи `docs/AI_USE.md` з таблицею: файл / що робив ШІ / хто. Закоміть, запуш у `main` і напиши в чат: **«Каркас готовий, всі оновлюємось»**.

**Готово, коли:** кожен відкриває свою Sandbox-сцену, натискає Play, бачить DebugPanel, і час іде.

## Задача 2. 2.5D-світ як у Don't Starve Together (години 3–9)

**Мета:** світ тривимірний, а все живе й дрібне — 2D-спрайти. Інженер ходить по базі й по поверхні Місяця.

Пиши Claude по одному пункту.

1. **Камера:**
   - перспективна, нахил ≈ 40–45°, плавно слідує за інженером, колесо миші змінює масштаб;
   - обертання кроками по 45° (Q/E, як у DST) — тільки якщо лишиться час.
2. **Білборди:** скрипт `Billboard` повертає кожен `SpriteRenderer` до камери. Використовуй його для персонажів, роботів, каміння й предметів.
3. **Інженер:** WASD або клік по землі (Raycast). Спрайт у 3 напрямках: спереду, ззаду, збоку (дзеркалимо).
4. **Модулі — прості 3D-коробки:** підлога, низькі стіни, **дах окремим об'єктом**. Текстури малює 02, а меблі всередині — спрайти-білборди.
5. **Дах і затемнення, як у Project Zomboid:**
   - у модулі є тригер-зона; коли інженер заходить, дах плавно зникає;
   - вулиця темнішає: зменшуєш головне світло, всередині модуля власне світло;
   - виходиш — усе повертається.
   > Зроби ModuleInterior: тригер, плавне зникнення даху (прозорість або вимкнення рендерера), затемнення вулиці через інтенсивність головного світла й ambient, власне світло всередині. Пиши Astronaut.InsideSlot для того, хто зайшов.
6. **Поверхня Місяця:** база в центрі, навколо територія приблизно 3–4 екрани. На ній розстав точки `PoiMarker` з `PoiId`:
   - темний кратер з льодом (темна земля, холодне світло);
   - 2–3 місця для зразків;
   - посадковий майданчик;
   - 2–3 точки з фактами.

   Коли інженер підходить, світ ставить `Discovered = true`. Текстуру ґрунту можна взяти з Moon Trek (роль 06 знайде).
7. **Астронавти:**
   - йдуть до `TaskTarget` по прямій, без NavMesh;
   - коли дійшли, `AtTaskSite = true`;
   - щокадру пиши `InsideSlot`;
   - над головою іконка стану (ситість, здоров'я, доза), але тільки коли щось не так. Іконки малює 02.
8. **Роботи:** їдуть до `TargetSlot`, а коли будувати нічого, стоять біля ангара. Якщо інженер стоїть біля будови, `EngineerNearby = true`.
9. **Слоти модулів:** 10–12 розставлених точок `ModuleSlot` з `SlotId`. `ModuleView` показує «будується», поки `BuildHoursLeft > 0`, а потім готовий модуль.

**Перевірка:** у DebugPanel замов модуль. Роботи їдуть, модуль з'являється. Зайди в модуль — дах зникає, вулиця темнішає.

## Задача 4. Веб-збірка (години 9–15, потім кожні кілька годин)

1. File → Build Profiles → **Web** → Switch Platform.
2. Player Settings → Publishing Settings → Compression Format = **Gzip** і ✔ **Decompression Fallback** (або Compression = Disabled). Без цього itch.io часто показує порожню сторінку.
3. Build у `Builds/` (вона в `.gitignore`). Збірка займає 5–15 хв, тож **ніколи не лиши її на останню годину**.
4. itch.io:
   - Kind of project = HTML;
   - zip з умістом збірки;
   - ✔ This file will be played in the browser;
   - 1280×720, кнопка Fullscreen;
   - сторінка публічна, без пароля, і перевір її в режимі інкогніто.
5. SaveSystem зберігає гру наприкінці кожного дня. У меню є кнопка «Продовжити».

**Готово, коли:** розділ 1 проходиться в браузері на чужому комп'ютері.

## Типові проблеми

| Проблема | Рішення |
|---|---|
| Рожеві або фіолетові спрайти | Матеріал не під URP. Постав шейдер `Sprite-Lit-Default` або `Sprite-Unlit-Default` |
| Порожня сторінка на itch.io | Decompression Fallback (див. задачу 4) |
| «The type or namespace could not be found» | Скрипт поза `Game.asmdef` або бракує посилання в asmdef |
| Конфлікт у `.unity` | Візьми свою версію сцени, а чужі зміни в сцені зроби вручну |
| Хтось змінив чужу зону | Не зливай PR, попроси перенести зміни або домовитися з власником |
